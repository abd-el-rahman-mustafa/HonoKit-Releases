# HonoKit — downloads have moved

HonoKit is now open source. Each app's code, issues and downloads live in its own repository:

| App | Repository | Download |
| --- | --- | --- |
| **HonoKit for Windows** | [HonoKit](https://github.com/abd-el-rahman-mustafa/HonoKit) | [Latest release](https://github.com/abd-el-rahman-mustafa/HonoKit/releases/latest) |
| **HonoKit for Android** | [HonoKit-Android](https://github.com/abd-el-rahman-mustafa/HonoKit-Android) | [Latest release](https://github.com/abd-el-rahman-mustafa/HonoKit-Android/releases/latest) |

This repository keeps the older releases (up to Windows 0.19.0 and Android 0.10.4). Installed copies
that still read it update to those versions, and from then on they update from the new repositories
by themselves: there is nothing to do.

Found a problem? Report it in the app (Settings › About › Report a problem), or open an issue in the
app's repository.
